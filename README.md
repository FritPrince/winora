# Winora

Boutique premium de produits digitaux pour l'Afrique francophone.

Le plan complet du projet (positionnement, identité de marque, fonctionnalités,
architecture, paiement, modèle de données, sécurité, feuille de route) est dans
[`PLAN.md`](./PLAN.md) — à lire avant de contribuer.

Conventions de code : [`# Charte et Conventions de Développement.md`](<./# Charte et Conventions de Développement.md>).

## Stack

Next.js (App Router) · TypeScript · Tailwind CSS v4 · Supabase · Vercel · Moneroo

## Démarrer en local

```bash
npm install
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000).

## Variables d'environnement

Copier `.env.example` en `.env.local` et renseigner les clés (voir le fichier
pour le détail de chaque variable).
